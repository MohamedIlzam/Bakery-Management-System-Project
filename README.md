# Kodikara Bake House Management System

This is a **web-based bakery management and sales distribution system** designed for **owners** and **salesmen**.  
The system helps manage bakery products, vehicle deliveries, and sales reports.

## Features

- **Secure Login** – Only owner and salesman can access the system.
- **Dashboard** – Central hub with quick access to operations.
- **Deliver to Fairs** – Assign vehicles, drivers, and products for fair deliveries. Track remaining stock and generate daily sales reports.
- **Deliver to Shops** – Record shop supplies with shop details, owner information, and supplied products.
- **Reports** – View daily and monthly reports, including profit analysis from fairs and shops.

## Tech Stack

- **Frontend**: React.js  
- **Backend**: Spring Boot (Java)  
- **Database**: MySQL
